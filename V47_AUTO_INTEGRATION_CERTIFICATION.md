# v47 — Universal Auto Integration Certification

v47 extends v46 without removing any existing file or contract.

## Certification rule

Structural discovery is **not** certification. A module can become production eligible only when the live Odoo/PostgreSQL runtime proves:

`Install → Discover → Models → Groups → Capabilities → Adapter → Tool → Authorization → Risk → Approval → Commit → Event → Workflow → Notification → Audit → AI → RAG → Frontend → Security → E2E`

Every failed or unexecuted runtime probe blocks promotion.

## Supported certification targets

Purchase, Stock, Accounting, Manufacturing, CRM, HR/HR Holidays, Sales, Project, Documents, Calendar, Helpdesk, and HR Expense when installed.

## No deletion rule

v47 is an additive release. The release audit must report zero files missing compared with v46.
