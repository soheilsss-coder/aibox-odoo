# Lovable prompt

Build the frontend as a premium AI-native enterprise operating system, not a generic ERP dashboard or chatbot. Do not expose the underlying ERP/platform name anywhere in UI. Use API-first architecture and capability-driven visibility. Core areas: Home, AI Workspace, Tasks, Calendar, Departments, Documents, Knowledge, Approvals, Agents, Notifications, Integrations, Administration. AI chat must support text, voice input/output, file/image upload and analysis, citations, tool execution status, approvals and generated artifacts. Every department can have private/team/department/company chats and a department Agent. Every role can have a dedicated Agent, but the Agent can never exceed the logged-in user's effective permissions. Documents support personal, team, department, company, restricted and confidential scopes, sharing/revocation/versioning and Knowledge indexing with the same ACL/FGA boundary. Artifacts include CSV, Excel, PDF, Word, PowerPoint, SVG/chart and images when a provider is configured. Never put business logic or authorization in the frontend; the backend is authoritative. Make the UI premium, fast, accessible, responsive and brandable.
