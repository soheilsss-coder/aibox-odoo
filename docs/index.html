اتصال به نسخهٔ در حال اجرا

این صفحه روی GitHub Pages فقط فایل ثابت سرو می‌کند؛ بک‌اند جای دیگری اجرا می‌شود. آدرس appliance خودت را وارد کن تا همین رابط کاربری به آن وصل شود.

هنوز تستی انجام نشده.
چرا بک‌اند اینجا اجرا نمی‌شود؟
  • GitHub Pages فقط HTML/CSS/JS ثابت سرو می‌کند. Odoo یک سرویس پایتون با PostgreSQL است و روی Pages قابل اجرا نیست — با هیچ workflow ای.
  • پس این لینک رابط کاربری محصول را نشان می‌دهد؛ داده‌ها و LLM از appliance خودت می‌آید.
  • اگر appliance روی دامنهٔ دیگری است، در Odoo باید AI_GATEWAY_ALLOWED_ORIGIN روی آدرس همین Pages تنظیم شود، وگرنه مرورگر درخواست را به خاطر CORS رد می‌کند.
  • کوکی نشست باید cross-site ارسال شود: AI_GATEWAY_COOKIE_SECURE=1 و AI_GATEWAY_COOKIE_SAMESITE=None (نیازمند HTTPS روی بک‌اند).

چه چیزی کجا اجرا می‌شود

GitHub Pages (اینجا)رابط React + صفحهٔ فرود. بدون سرور، بدون داده.
Appliance شما (Odoo)ماژول‌های ai_*، gateway، ACL، ممیزی، RAG.
PostgreSQL + pgvectorداده‌های ERP و بردارهای اسناد.
LLM APIهر ارائه‌دهندهٔ OpenAI-compatible؛ با متغیر محیطی انتخاب می‌شود.

جایگزینی LLM لوکال با API

مسیر کد تغییر نکرده — فقط llm.provider حالا یک آدرس و کلید خارجی نگه می‌دارد. تشخیص ارائه‌دهنده خودکار است:

export AI_LLM_API_BASE=https://api.openai.com/v1
export AI_LLM_API_KEY=sk-...
export AI_LLM_MODEL=gpt-4.1-mini

# Embedding جدا تنظیم می‌شود (Groq و OpenRouter اصلاً embedding ندارند)
export AI_EMBEDDING_API_BASE=https://api.openai.com/v1
export AI_EMBEDDING_MODEL=text-embedding-3-small
export AI_EMBEDDING_DIM=1536

python odoo-bin shell -c odoo.conf -d <db> --no-http < runtime_workers/seed_api_inference.py
python runtime_workers/verify_llm_api.py --verbose

آدرس‌های تشخیص‌داده‌شده: OpenAI، Gemini، Groq، OpenRouter، Anthropic، Mistral، DeepSeek، xAI، DeepInfra، Together و هر endpoint سازگار (vLLM، Ollama، LM Studio).
